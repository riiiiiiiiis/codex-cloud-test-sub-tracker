## Исходный README

# SubTrack Cloud

Персональный веб‑сервис для учёта платных подписок с облачным хранением данных, аналитикой расходов и поддержкой двух языков интерфейса.

## Возможности

- Регистрация и авторизация по email/паролю с сообщениями об ошибках и подсказкой подтвердить почту после входа.
- Добавление, редактирование, отключение и удаление подписок через модальное окно с валидацией данных и подтверждением опасных действий.
- Дашборд с ежемесячными и годовыми тратами, подсчётом активных подписок, количеством платежей на 30 дней вперёд и лентой ближайших платежей на 7 дней.
- Автоматический пересчёт сумм по периодам (неделя/месяц/квартал/год) и конвертация между валютами USD/EUR/RUB в соответствии с выбранными настройками профиля.
- Публичный лендинг с описанием продукта, демо‑аналитикой, блоком FAQ и переключателем языка.
- Настройки профиля: переключение языка, выбор отображаемой валюты, отметка подтверждения почты, экспорт подписок в JSON и очистка локальных данных.
- Поддержка тёмных/светлых оттенков интерфейса, адаптивная вёрстка, всплывающие уведомления и модальные окна подтверждения.

## Стек

- Node.js (без внешних зависимостей) — HTTP‑сервер и файловое хранилище данных (`data/*.json`).
- Чистый HTML/CSS/ES‑модули — клиентская часть и управление состоянием приложения.

## Структура

```
src/server.js        # HTTP API и раздача статики
public/              # Клиентские страницы и ресурсы
  index.html         # Лендинг
  login.html         # Страница входа/регистрации
  dashboard.html     # Защищённый дашборд
  settings.html      # Настройки
  js/*.js            # Логика страниц, API, UI
  css/styles.css     # Общие стили
data/                # JSON-хранилище пользователей, подписок и сессий
```

## Запуск

```bash
npm install  # зависимостей нет, команда сохранит lock-файл при необходимости
npm start    # сервер доступен на http://localhost:3000
```

Перед первым запуском создаются файлы `data/users.json`, `data/subscriptions.json` и `data/sessions.json`.

## Проверка

```bash
npm test
```

Команда выводит заглушку, поскольку отдельные тесты не подключены.

## Учёт и аналитика

- Подписки сортируются по дате следующего платежа и группируются по категориям при отображении ближайших платежей.
- Данные пересчитываются на месяц и год, суммы конвертируются в выбранную пользователем валюту.
- Валидация на клиенте и сервере предотвращает сохранение пустых или некорректных значений.

## Переводы

Все текстовые блоки поддерживают русский и английский языки (см. `public/assets/translations.js`). Выбранный язык сохраняется между сессиями и синхронизируется с настройками профиля.
